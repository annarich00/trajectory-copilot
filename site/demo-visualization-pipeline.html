Demo visualization pipeline for the rendezvous workflow

This standalone page mirrors the walkthrough style from the project’s evidence pages and replays four stored demo runs: Demo A, Demo B, Demo C, and Demo D’s 15-time transfer scan.

About these recorded demos

Demo A is NOT VERIFIED after a GMAT numerical disagreement. Demo B is VERIFIED at 20 m / 0.05 m/s. Demo C is UNSUPPORTED and stops before solving or GMAT. Demo D’s 15-time scan identifies a solver-only minimum but is NOT VERIFIED after GMAT disagreement. The replay is embedded, local, and needs no server or API key.

Demo D visual scope: Demo D trajectory/burn and GMAT-comparison visuals show only the selected five-period minimum candidate. Its delta-v-versus-time plot contains all 15 evaluated transfer times.
