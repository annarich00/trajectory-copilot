Standalone walkthrough

Demo visualization pipeline for the rendezvous workflow

This standalone page mirrors the walkthrough style from the project’s evidence pages, but it focuses on the three stored demo runs: Demo A, Demo B and Demo C.

Recorded run, sample data. This page replays saved data with no server and no API key. Demo A, Demo B and Demo C are embedded directly in site/data/demo-runs.js (regenerate with scripts/build_embedded_demo_runs.py), so this page works even opened directly as a file, with no local server required. To instead load any other captured run through a local server, open this page with ?case=<case_id> (it tries artifacts/runs/<case_id> then artifacts/runs/<case_id>/bridge) or ?runDir=<exact path>; the loaded directory is then shown below the toolbar.
